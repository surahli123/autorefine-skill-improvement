# AutoRefine Plugin Metadata

This directory contains the Claude plugin manifest for AutoRefine.

It points at the shipped runtime bundle in [`./autorefine`](../autorefine), which is the installable skill package public users should copy into their Claude Code skills directory.

## What this plugin describes

- package name: `autorefine`
- shipped bundle path: `./autorefine`
- public repo: `https://github.com/surahli123/autorefine-skill-improvement`
